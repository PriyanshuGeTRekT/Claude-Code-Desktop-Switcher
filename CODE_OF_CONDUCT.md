# Code of Conduct

## The short version

Be decent to people. This is a small utility repo, not a place worth being unpleasant in.

## What is expected

Assume good faith. Most people filing an issue are confused, not careless, and most people
reviewing a pull request are busy, not hostile. Give others the benefit of the doubt and
keep discussion focused on the code and the problem.

Bug reports, questions and disagreement about technical direction are all welcome. Blunt
technical feedback is fine. Personal attacks are not.

## What is not acceptable

- Harassment, insults, or demeaning comments, including about someone's identity or
  background
- Sexualised language or unwanted attention of any kind
- Publishing anyone's private information without their permission
- Sustained disruption of discussions or deliberately derailing threads

## Scope

This applies in issues, pull requests, discussions, commit messages, and anywhere else
this project is being represented.

## Enforcement

Report problems privately to the maintainer. Use GitHub's private vulnerability reporting
for anything sensitive, or contact the repository owner directly through their GitHub
profile.

> Maintainer: replace this line with a contact address if you would prefer reports by
> email.

Reports will be handled as promptly as is reasonable for a spare time project, and the
reporter's identity will not be shared. Depending on severity, the response may be a
warning, deleting or editing comments, or blocking someone from the repository.

## Attribution

This document is written for this project. If you would prefer a widely recognised
standard instead, the [Contributor Covenant](https://www.contributor-covenant.org) is a
good drop in replacement.
